MAF Footwear Limited Logo Instructions
=======================================
The uploaded logo image (Footwear_Log.jpg) should be saved as:
  maf-logo.png  (in this same folder)

Path: C:\xampp\htdocs\maf-website\public\images\maf-logo.png

The website uses the logo in:
1. Navigation bar (inline SVG - automatically shows)
2. Footer (inline SVG - automatically shows)

To use your actual logo image instead of the SVG:
- Save your logo as: public/images/maf-logo.png
- It will automatically appear in header and footer
